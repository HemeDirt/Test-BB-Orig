## Правила области
1. Новые файлы после разбора раскладываются по категориям; читаемое — всегда в `10_docs/`.
2. Каждый скрипт `.py` хранится с дублем `.txt`/`.json` (пользователь не может передавать `.py`).
3. Полные тексты карт и логов в контекст не загружаются: в бриф идёт только выжимка.
4. Симуляции не проводятся; все числа берутся из `20_data/` как есть.
5. Ситуации из `10_docs/ситуации_пробные/` в правила и партии не подмешиваются, пока не сказано иное.
