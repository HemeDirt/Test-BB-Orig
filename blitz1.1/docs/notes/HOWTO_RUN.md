# БЛИЦ БОЙ — как запустить (версия «канон 24», октябрь 2026)

## Что изменилось
Колоды теперь **канонные**: ровно **24 карты каждой категории** из твоих расшифровок фото
(файлы `canon/cards_*.md` → собираются в `canon/decks.json`). Старые колоды на сотни карт удалены.

## Самый простой путь — ничего не устанавливать
Открой файл **`web/index.html`** (в папке `web`) двойным кликом в любом браузере —
это готовая страница игры: столы 8 игроков, ход партии по циклам, все канонные колоды.
Данные вшиты внутрь файла, интернет и Python не нужны.

## Запуск своей новой партии (через Python)
1. Установи Python 3 с python.org (при установке поставь галочку **Add Python to PATH**).
2. Открой папку проекта: в Проводнике зажми Shift + правый клик по пустому месту →
   «Открыть окно PowerShell здесь» (на Mac: «Открыть терминал здесь»).
3. Набери команду и нажми Enter:
   ```
   python bb.py play --seed 5
   ```
   (`py bb.py play --seed 5` если `python` не распознаётся — это для Windows)
   Получится полный лог новой партии. Другой `--seed` = другая партия.
4. Красивая страница именно этой партии:
   ```
   python make_web.py 5
   ```
   затем открой `web/index.html`.
5. Серия партий + статистика: готовый прогон 100 партий на канонных колодах лежит
   в `batch_canon24.json` (медиана окончания — цикл 4, первая смерть в ц.2 в 96%,
   Жатва в 76%). Заново: `python bb.py batch --out batch_canon24.json`.

## Файлы
| Файл | Что это |
|---|---|
| `game_sim.py` | симулятор полной партии (все механики v3: d20, таблицы А/Б/В, ОР, призраки, Жатва, ставки, магазин мёртвых, спецкарты, обменки, профессии) |
| `bb.py` | запускатор: `play`, `html`, `deck --show`, `batch` |
| `canon/decks.json` | КАНОННЫЕ колоды по 24 карты (генерируется из canon/*.md) |
| `build_canon_decks.py` | пересобрать decks.json после правок карт |
| `make_web.py` + `template_index.html` | генератор интерактивной страницы партии |
| `web/index.html` | ГОТОВАЯ страница партии seed 777 (просто открой в браузере) |
| `batch_canon24.json` | результаты теста 100 партий на каноне |

## Как обновить файлы на GitHub (через сайт)
Я работаю в копии репозитория и не могу писать напрямую в твой GitHub.
Чтобы изменения появились у тебя: скачай файлы отсюда и залей в репозиторий:
открой страницу репо → кнопка **Add file → Upload files** → перетащи файлы →
внизу напиши комментарий → **Commit changes**. Всё, main обновился.
