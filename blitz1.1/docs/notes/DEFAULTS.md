# ПРИНЯТЫЕ ТОЛКОВАНИЯ ПЕЧАТНОЙ РЕД. №2 (по ответам пользователя, 20 пунктов)
1. Раскрытие: отдельная механика выбора игрока, 2 карты за цикл (REVEAL_PER_CYCLE=2); все карты закрыты до раскрытия. Профессии: активные (игрок включает сам) / пассивные-триггерные (Тварь, Буддист, Мэр, Наёмник, Сменщик, Алкоголик) / флейвор (Антиковед).
2. Смерть от собственного отката = смерть, «кормящая» Жатву: дополнительная случайная смерть в этот цикл не добавляется (selfkill считаетcя смертью игроков → Жатва не стреляет повторно).
3. РПДС: меню типов (самолечение, мир, добавление, удаление, перемешивание, вхолостую) — ВСЕ через таблицу В; «вхолостую» = бросок без эффекта.
4. Обмен: тянется в начале КАЖДОГО цикла; активируется только если игрок НЕ потратил РПД в свой ход (used_rpd); объявляется-показывается-срабатывает-сбрасывается; в конце цикла все сгорают; реактивные (ОТРАТ/ПУСТО/СПАС) взводятся на следующий круг.
5. Масс-кража: успех 18–20 = по одной карте с каждой цели; провал = автор отдаёт целям ВСЮ руку (включая закрытые).
6. Масс-убийство: успех = все цели умирают сразу (как напечатано).
7. Состояния: Кондуктор = лимбо с 50/50 возвратом каждый цикл (не мёртв); Судья = смерть навсегда; кик-спецка = лимбо на 2 цикла (без жетонов); если при лимбо выполняется порог ситуации — лимбо становится формально мёртвым (limbo_lost). Лимбо = жив, но не взаимодействует со столом и наоборот.
8. Машина времени: бросок порога после КАЖДОЙ смерти; число закрытых карт сохраняется; при пустой колоде категории карта не добирается.
9. Чистилище: W = dN − 2 (минимум 1); конец при живых ≤ W.
10. Амкары: команды открыты; призрак теряет команду до воскрешения; тени/эффекты призраков могут идти любой команде.
11. Алкоголик: 5 чисел = границы полос таблицы А, 3 числа = границы Б и В (реализовано как личные таблицы).
12. Наёмник: +2 прибавляется к числу после броска; нат-проверки смотрят сырой кубик.
13. Мудрец: истина = вилдкард (авто-убийство / авто-успех / отмена последнего / раскрыть цель на 2).
14. Любовники: смерть триггерит смерть, изгнание/лимбо триггерит лимбо пары.
15. Тень «cancel» = отмена результата (последствия), действие считается потраченным.
16. Колоды: только печатная (24×категория + 24/24/24/24 + 6 ситуаций).
17. Личности: 9 измерений (aggr/help/neut/theat/thief/chaos + скрытые blood/coop/detach) + скрытая повестка с p=0.25 (secret_kill / sabotage_heal / protect_one / hidden_hoard).
18. Модель времени НЕ используется; отчёт = точное описание партии + частоты.
19. Прогоны-тесты выполняются у агента (в песочнице).
20. D6 в bb_full не моделируется; агрегаты ≤ 100 партий за прогон.

## B15 (№7 лимит руки — hand_limit)
- hand_limit (default None = канон бит-в-бит): потолок ЗАКРЫТЫХ карт в руке. Карта, входящая сверх потолка, СГОРАЕТ (сброс, вне обращения; строка лога «🔥 лимит руки», событие hand_limit_burn).
- Раскрытые карты (публичная зона) в потолок не входят; обмен 1-на-1 (сделки, хроно-обновление рук) размер не меняет — лимит не трогают; тень «close» (вернуть раскрытую в руку) на полной руке не срабатывает — карта остаётся раскрытой; штраф провала кражи/масс-кражи в полную руку — карта сгорает (полная рука слегка страхует от провала кражи — осознанный побочный эффект).
- Гард: hand_limit ≥ 7 = len(CATS) (стартовая рука — по одной карте в 7 категориях; Буддист тоже пересдаёт 7). Лимит 7 = режим «нулевого накопления».
- Замер (2000 партий + 6 стресс-конфигов): экономика печати самоограничена, пик руки ≤9 всегда; лимиты 9/12/15 инертны, 7 — Δend ≤0.25 цикла. Рекомендация: default None, 9 = предохранитель для домашних партий, 7 = вкусовой дефицит. Канон не меняется.

## B16 (№9 драфт раскрытых — draft)

## B22 (№12 тильт ботов — tilt)
- tilt (default False = канон бит-в-бит): собственный откат/крит-провал сдвигает веса агрессии бота на один цикл (остаток текущего + следующий). temper = aggr + blood − detach (детерминированно из pers, ≥ +0.25 — «вспышка»: kill ×1.35, wound ×1.25, mass ×1.2, skip ×0.7; ≤ −0.25 — «заморозка»: kill ×0.75, wound ×0.8, mass ×0.8, skip ×1.3, heal ×1.15; между — без сдвига). Коэффициенты НЕ тюнились (меню №10 — канон-вероятности заморожены; тильт множит веса только под HOUSE-флагом, как fear/panic).
- Триггеры (только собственные провальные исходы): «откат» — SELF-полоса таблицы А (W1/W2/DEATH_SELF); «крит-провал» — FAIL любой своей проверки Б/В (кража, унижение, лечение, мародёрка, РПДС); «масс-провал» — провал массового ранения/масс-кражи. ## B23 (№13 планирование резерва — reserve / reserve_gate / reserve_strict)
- reserve (default False = канон бит-в-бит): с реактивной картой обмена на руке бот отказывается от заявки РПДС (строка «🧊 резерв — РПД не тратятся ради обмена», событие reserve, 71-й шаблон) и мягче тратит РПД (вес skip ×(1+reserve_value)); reserve_value = RV(карты) × угроза × 0.9, RV = 1.0 ОТРАТ / 0.7 ПУСТО / 0.0 СПАС, угроза = (0.35 + 0.5×агрессия живых противников) × (живых−1)/N. - reserve_gate (default False): правило обмена читается буквально — гейт «РПД не тратились» распространяется и на реактивные карты (счётчик reserve_gate_blocked). reserve_strict (default False, нужен вместе с gate): жёсткое планирование — choose() детерминированно возвращает skip, т.е. бот сознательно пропускает ход целиком (ГСЧ не трогает: число вызовов rng не меняется).
