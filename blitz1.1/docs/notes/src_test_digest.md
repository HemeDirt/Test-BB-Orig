# src/ И test/ — ДАЙДЖЕСТ (build_v5, censor_fix, check_clean, export_v5_xlsx, md2docx, t2, audit_full, one_search, verify_any)
## build_v5.py: сборка редакции 5
Вход src/final_v5.json → v5/final/{1..10}_{slug}.txt (10 файлов по категориям) + карты_v5_по_категориям.md. Заголовок md: «Редакция 5 = редакция 4 с полной чисткой текстов… заменено карт — 89; состав категорий, механики и баланс не изменились»; дата сборки 2026-09-28. ⇒ ТАЙНА ПАПКИ .v5 РАСКРЫТА: это v5/final/ (10 txt колоды ред.5) — 189 870 байт из скриншота.
## censor_fix.py: таблица FIX = категория → индекс → новый чистый текст
Замены «странных» карт по индексам (кат1: 12 шт, кат2: 10, кат3: 18, кат4: 3, кат5: 9, кат6: 7, кат7: 3, кат8: 9, кат9: 10; всего 81 замена; в build_v5 сказано 89 — расхождение зафиксировано). Комментарий пользователя: умерший чат обходил цензуру Qwen, выдавая «странным» характеристикам коды (unicode-escape в файле). censor.py пользователь НЕ присылает осознанно («фикс основан на предыдущем файле, который не справился») — принят как отсутствующий по решению.
## check_clean.py: контроль чистоты всего проекта
1) колода: dirty-карты через censor.dirty + дубли внутри категорий; 2) обход всех файлов (.md/.txt/.csv/.json/.py + xml внутри .xlsx/.docx): строки с censor.dirty + счёт слова-табу TABOO = «бункер» (собрано из кодов 0x0431,0x0443,0x043D,0x043A,0x0435,0x0440); SKIP_DIRS включает uploads/ (исходники пользователя не проверяются). exit code 0/1.
## export_v5_xlsx.py → карты_настолка_v5.xlsx
openpyxl-генератор книги ред.5: листы категорий (ПРОФЕССИЯ и ТЕНЬ = split2 «имя — механика»), колонка «Статус» (в игре/свалка/под вопросом) с DataValidation; «свалка» гаснет (FormulaRule) и попадает в таблицу «СВАЛКА» внизу того же листа через массивные формулы SMALL(IF(...)); скрытый лист _ДАННЫЕ (зеркало: статус-формулы, ссылки, флаги поиска SEARCH, нумерация COUNTIF); лист ПОИСК (2 входа: слово+статус, 500 строк выдачи INDEX/MATCH, HYPERLINK-прыжок, счётчик C5); лист СВОДКА (живые COUNTA/COUNTIF по категориям + ИТОГО). Всего карт 2686.

## test/audit_full.py: структурный аудит карты_настолка_v5.xlsx
Сверка: порядок листов (СВОДКА, ПОИСК …, _ДАННЫЕ последний); контент 1:1 с final_v5.json (включая split-разбор); плашка/шапка/вместимость СВАЛКИ и массивность формул SMALL(IF; dv (состав списка), 2 правила подсветки, автофильтр, freeze A3, max_row; _ДАННЫЕ hidden + 40 случайных гиперссылок на живые строки; ПОИСК C5/500 строк/MATCH/HYPERLINK; СВОДКА формулы по категориям + ИТОГО; TABOO=0; итог: 2686 карт.
## test/one_search.py: один прогон ПОИСКА в отдельном процессе через движок `formulas` ( recalc xlsx ), сверка выдачи и счётчика с эталоном из открытых ячеек.
## test/verify_any.py: универсальная проверка любой собранной книги
Сама определяет размеры листов; помечает каждую 37-ю карту «свалка», каждую 74-ю «под вопросом»; пересчитывает движком `formulas`; сверяет автосвалку (порядок и механику), СВОДКУ (всего/в игре/вопрос/свалка + ИТОГО), ПОИСК (5 наборов термин/статус), структуру (dv, 2 подсветки, массивные формулы).
