# БЛИЦ БОЙ — рабочая папка проекта

Здесь лежит **рабочий проект** игры «БЛИЦ БОЙ» после реорганизации (октябрь 2026).
Всё, что было навалено в одну кучу, разложено по папкам. Мусор и дубликаты удалены.

## С ЧЕГО НАЧАТЬ (тебе достаточно двух команд)

Все команды пишутся внутри этой папки (`blitz/`):

```
python3 blitz.py test        # проверка: всё ли работает (движок + web + JS-тесты)
python3 blitz.py play --seed 5   # сыграть новую партию (другой seed = другая партия)
```

Другие команды покажет `python3 blitz.py` (без аргументов) или `python3 blitz.py help`.

| Команда | Что делает |
|---|---|
| `python3 blitz.py play --seed N` | полная партия 8 игроков в терминале |
| `python3 blitz.py batch --games 100` | серия партий + статистика в json |
| `python3 blitz.py html --seed N` | красивая страница партии → сохранится в `viewer/` |
| `python3 blitz.py web --seed N` | обновить интерактивную страницу-наблюдатель → `docs/preview/index.html` (один самодостаточный файл для GitHub Pages). Перемотка: по ходам (⏮⏭, стрелки), по циклам (кнопки «⏪ ц− / ц+ ⏩», клавиши PageUp/PageDown), выпадающие списки «цикл» и «ход» для перехода к конкретному месту партии |
| `python3 blitz.py deck` | статистика канонных колодов (по 24 карты) |
| `python3 blitz.py test` | все проверки разом |

Если `python3` не распознаётся (Windows) — пиши `py` вместо `python3`.

## Структура папок

| Папка | Что внутри | Тронуть можно? |
|---|---|---|
| `blitz.py` | **главная менюшка**, с неё всё запускается | это точка входа |
| `src/` | **ЯДРО ИГРЫ**: `game_sim.py` (симулятор), `bb.py` (команды), `make_web.py`+`template_index.html` (генератор страницы), `canon/decks.json` (канонные колоды 7×24), `web/` (страницы для GitHub Pages), тесты js | только по делу |
| `docs/` | правила (`rules/`), заметки чата (`notes/`), отчёты (`reports/`), расшифровки карт (`cards/`) | читать можно |
| `docs/preview/` | сюда кладётся свежесгенерированная игровая страница | результат |
| `viewer/` | готовые HTML-страницы прошлых партий (просмотр логa) | результат |
| `tools/` | живой инструмент: `batch_stats.py` — быстрая статистика (1000 партий за секунду). Старые экспериментальные скрипты → `archive/tools_old/` | по необходимости |
| `tests/` | `run_tests.sh` — полный приёмочный прогон (5 шагов), зелёный | запускай после правок |
| `archive/` | **СТАРЫЕ наработки**: мёртвый движок bb_full+патчи B1–B25, обломки, docx-отчёты, zip-архивы. Ничего не удалялось — всё сложено сюда | не запускать |

## Что работает, а что нет (честный статус)

✅ **Работает и проверено запуском:** связка `src/game_sim.py` + `src/bb.py` + `src/make_web.py` + `viewer/game.html` (JS-движок интерактивной страницы) + `src/canon/decks.json`.
`python3 blitz.py test` проходит целиком (python-партия, генерация страницы, 30 JS-партий).
С октября 2026 партии играются **функцией** `game_sim.play_game(seed)` — один импорт, без subprocess:
`bb.py batch` и `tools/batch_stats.py` считают статистику в разы быстрее (1000 партий ≈ 0.8 сек).

❌ **Не работает (и не должно):** `archive/old_engine/` — старая линия bb_full.py с патчами B11–B25. Она зависела от файла `deck_print.json`, которого нет ни в репозитории, ни в твоём zip. Это история; живёт в архиве для справки. Сюда же убраны старые VIEW-страницы (`archive/viewer_old/`), дубли web-страниц (`archive/web_old/`) и мёртвые инструменты (`archive/tools_old/`). Ничего не удалено — только переложено.

## Как пользоваться (шпаргалка для нуля)

Рабочая папка проекта — `blitz/`. Внутри неё 4 «живых» вещи:

| Что | Команда / файл | Результат |
|---|---|---|
| Играть партию в терминале | `python3 blitz.py play --seed 5` | полный лог боя |
| Живая игра в браузере | `docs/preview/index.html` (кнопки, броски) | открывается двойным кликом |
| Страница сыгранной партии | `python3 blitz.py html --seed 5` → `viewer/VIEW_bb_seed5.html` | запись партии |
| Проверки «всё ли цело» | `bash tests/run_tests.sh` | должно писать «ВСЁ ЗЕЛЁНОЕ» |

Удаление файла: `rm путь/к/файлу`. Новая папка: `mkdir имя`. Перенос: `mv старое новое`.
Удаляй только то, что не нужен для четырёх строк выше — сомневаешься — спроси сначала.

Старая линия движка B1–B25 (`bb_full.py`, ~17 патчей, старые тесты) мертва: нет файла `deck_print.json`.
Всё это лежит в `archive/old_engine/` и `archive/old_tests/` — не запускать, просто хранение истории.
