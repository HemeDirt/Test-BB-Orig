## Лист «Ситуации» (6 карт, печатные редакции)

**Самолёт в Гренландию.** Парашютов «в два раза меньше, конкретно для вас». Правила: общее число
игроков, делённое на два.

**Помидор, забывший тройку.** **РЕШЕНИЕ 2026-10: карта выводится из печатного набора** как слишком
странная и непонятная; в следующем тираже ситуаций пять. Ниже — текст текущего тиража для архива.
Флейвор: очередь на ПВЗ. Правила: общее число игроков, делённое на
два; **в режиме требуется избегать любых упоминаний тройки, сумм связанных с 3 и всего косвенно
с ней связанного; при нарушении игрок автоматически умирает**.

**Поле на остановке.** Правила: **должен выжить только один** (поле сужается, пока не убьёт всех).

**Чистилище.** Правила: число мест в раю неизвестно; бросается кубик с числом граней по числу
живых (при 8 — d8), выпавшее число = число мест; **если нужного кубика нет — бросают d20 и берут
приближённое значение (при 8 игроках и 17 на кубике — 7)**.

**Пьяная хронология.** Печатный текст = рабочая редакция пользователя (см.
`ПЬЯНАЯ_ХРОНОЛОГИЯ_РЕД2.md`): порог d20 старт 20, −1 за жертву, 5 убитых = 15; при столе меньше 10
значения брать с 10; «выпало ≥ требуемого» — найден создатель; если выжил только один — он и есть
создатель; после каждого цикла все сбрасывают карты и тянут новые, открытые остаются открытыми
навсегда, меняется только характеристика.

**Амкары и Касторама.** Правила: 1) число команд — голосованием до игры; 2) раунд распределения:
ведущий/стол по часовой выдаёт каждому порядковый номер; 3) бросается кубик: игрок, чей номер
совпал, переходит в соответствующую команду; 4) последних оставшихся можно распределить сразу или
разбиться на команды самим; 5) **побеждает команда, когда остальные уничтожены**.

## Флаги транскрипции
1. Спецкарта №23 первого цикла внутренне противоречива: «РП действия на игроков отменяются, можно
   использовать только РП действия на игроков» — по смыслу второе должно быть «на себя» (или
   наоборот). Требует правки перед следующим тиражом.
2. Печатное табу «Помидора» = автоматическая смерть за упоминание; в черновике ред.2 ситуаций
   стоял штраф +1 ОР. Печатная версия жёстче; черновик ред.2 более не актуален для этой ситуации.
3. Печатное «Поле» = последний выживший (порог 1), а не стандартный порог с давлением среды, как в
   черновике ред.2. Черновик ред.2 для этой ситуации более не актуален.
4. В печатном листе «Тень» карты чисто механические (24 штуки) и не совпадают с художественными
   Тенями колоды v4 (100 штук): для печати Тени = таблица эффектов призрака.
