# HTML-ВЬЮЕР ПАРТИИ (п.21 меню) — реализация B13, 2026-10-01

Одна самодостаточная страница на партию: интернет, CDN и внешние шрифты не нужны — данные партии
встроены в `<script>`, стили и логика инлайновые. Открывается двойным кликом; в просмотрщике
воркспейса превью интерактивное (iframe с `allow-scripts`).

## Быстрый старт

```bash
cd rebuild
python3 bb.py view --seed 777 --n 8 --sit plane --out VIEW_game_777_N8_plane.html
python3 bb.py view --seed 2026 --n 16 --sit base --out VIEW_game_2026_N16_base.html
python3 bb.py view --seed 606 --n 8 --sit base --cfg traitor=true --out VIEW_traitor.html
python3 bb.py play --seed 7 --n 12 --sit hrono --log g.log --events g.jsonl --html g.html   # всё сразу
python3 bb.py view --log g.log --out g.html          # страница из сохранённого лога (без снимков)
bash run_tests.sh                                     # приёмка: validate+fuzz+baseline+покрытие+вьюеры
```

Витрины в репозитории: `VIEW_game_777_N8_plane.html` (базовая партия-эталон),
`VIEW_game_2026_N16_base.html` (большой стол), `VIEW_game_606_N8_traitor.html` (предатели → пролог).

## Что починено попутно

1. **Старый парсер №18 терял 37% строк лога**: не ловил броски таблиц Б/В (в логе латинские
   `V`/`B`, а regex ждал кириллические `В`/`Б`), заявки РПДС, лечение, потерю жизни, массовые
   ранения/кражи, сделки, связки, лимбо, чучела, предателей, финалы ситуаций. Теперь 61 шаблон,
   покрытие 100% (проверяется тестом, а не на глаз).
2. **Обрезки текстов**: лог режет профессию до 26 символов, тень — до 30 + «…». Вьюер
   восстанавливает полные тексты: профессия/спецкарта/обменка — из снимков и порядка раздач,
   тень — сопоставлением с колодой (короткие карты ядро печатает целиком, поэтому пробуем
   и точное совпадение, и префикс).
3. **Чучело Таксидермиста** — это запись-дубль места в `P`; в список игроков не попадает
   (иначе N8 давал 9 карточек), выводится отдельной строкой.
4. **Пролог**: объявления до первого цикла (например, «предатели: [6] с целями [7]») раньше
   терялись — теперь цикл 0 = «ПРОЛОГ» со своей шапкой.
5. `bb.py events` теперь пишет полную ленту (53 типа + номер строки); старый формат №18 —
   флаг `--legacy`. `events_demo.jsonl` перегенерирован.

## Известные ограничения

- Страница из чужого лога (`view --log`) не имеет снимков: карточки мест пустые, ОР-график и
  обменки недоступны, лента/фильтры/поиск/лог работают полностью.
- Порядок спецкарт по местам берётся из записи перемешиваний ГСЧ (индекс 12 в потоке
  `random.Random(seed)`); если ядро когда-нибудь изменит порядок `shuffle`-вызовов, расшифровка
  спецкарт собьётся — `coverage_test` это не поймает, а `view_test` поймает (проверка
  «спецкарты расшифрованы ≥90%»).
- Вьюер не пересчитывает правила: он читает то, что выдало ядро. Спорные трактовки — в
  `data/rebuild/DEFAULTS.md`, а не в странице.
- `model_*.json` (если выгружать через `--json-model`) — рабочий артефакт, в репозитории не держим.
