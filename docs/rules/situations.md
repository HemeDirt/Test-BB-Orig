# СИТУАЦИИ — 6 карт, расшифровка с фото Ситуации-П.png + уточнения пользователя
## S1 «Самолёт в Гренландию» (зелёная)
Фабула: апокалипсис, самолёт, парашютов вдвое меньше.
Правило печати: общее число игроков, делённое на два.
Интерпретация: порог конца S = ⌊N/2⌋ (как база).
## S2 «Тройка» / «Помидор, забывший тройку» (фиолетовая)
Фабула: мир сломался из-за забытой цифры 3; упоминания тройки запрещены, нарушитель умирает.
Правило печати: общее число игроков, делённое на два.
Интерпретация: S = ⌊N/2⌋ + домовое правило штрафа (смерть за упоминание) — в симуляторе штраф не моделируется (словесное правило).
## S3 «Поле на остановке» (оранжевая)
Фабула: орбитальная установка, зона сужается.
Правило печати: должен выжить только один.
Интерпретация: S = 1; środowisko: в архивной версии поле било +1 ОР в циклах 2–4 — на печати этого НЕТ, уточнить у пользователя (см. вопросы).
## S4 «Чистилище» (тёмно-синяя)
Правило печати: мест в раю неизвестно; бросок кубика с гранями = числу игроков (D8 при 8); без кубика — D20 с округлением (17 при 8 → 7).
Интерпретация: W = randint(1, N) (или ceil-масштаб с D20 как домовое правило); конец при живых ≤ W.
## S5 «Машина времени» (розовая) = «Новый дивный мир»
Правило печати: после каждого убийства бросок d20; порог стартует 20 и падает на 1 за каждую жертву; при N<10 старт 10; сработка = «убили создателя».
УТОЧНЕНИЕ ПОЛЬЗОВАТЕЛЯ (канон): старт порога = 20 если N>10, иначе 10; порог −1 за каждую смерть; после каждого убийства бросок d20: если выпало ≥ порога — игра заканчивается; иначе игра идёт до одного игрока; если живых не осталось — победителей нет.
Интерпретация для симулятора: end-условие = (roll ≥ threshold) ИЛИ (alive ≤ 1); победители = выжившие на момент сработки; при total wipe — ничья. Сброс рук каждый цикл (печать) — уточнить (см. вопросы: это же хронория?).
## S6 «Дингари» (бирюзовая) = командный режим
Правила печати: 1) голосованием определяется число команд; 2) раунд распределения по кругу с порядковыми номерами; 3) бросок кубика: совпавший номер уходит в команду; 4) оставшихся дораспределяют; 5) побеждает команда, уничтожившая остальные.
Интерпретация: team-mode до последней команды (порог S отключён), команды ≥2 (число = параметр, по умолчанию 2).
