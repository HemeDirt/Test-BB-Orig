## 2. Моя модель игры: что держит баланс и веселье, где боль

- 2026-11-02. Двигатель веселья — объявление действия ВСЛУХ до броска: игрок берёт на себя обязательство (карта-основание, цель, результат), а общий d20 решает. Социальный контракт + случайность = хаос с лицом. [источник: SPEC.md §1, сообщение автора 0]
- 2026-11-02. Баланс удерживают три предохранителя: (а) урон считается вверх (0 ОР старт, 3 ОР смерть) — эскалация без отрицательных состояний; (б) порог конца = живых ≤ половина старта вниз — партия сама схлопывается; (в) Жатва — детерминированный таймер против затягивания: убивает случайного живого в конце цикла, где никто не умер от действий игроков. [источник: сообщение автора 0, QWEN.md §4]
- 2026-11-02. Смерть не выбивает: призрак со своей экономикой продолжает влиять — это снимает главную боль массовых игр (выбывший скучает). [источник: сообщение автора 0]
- 2026-11-02. Больные места [МОЯ ИНТЕРПРЕТАЦИЯ]: (1) подсистема карт+РПД — именно поэтому автор держит её в переработке: богатство вариантов воюет с простотой печати; (2) пороги ситуаций и расписания раскрытий — тонкая настройка, любое изменение требует регрессии; (3) при 2–20 игроках экономика одного кубика на всех — поведение на границах N надо проверять отдельно.
- 2026-11-02. Ориентиры, по которым я сверяю всё: архивная эпоха base N8 end 4.2–4.3; новая эпоха base N8 end 4.76 CI[4.41–5.11] при 100 партиях. [источник: QWEN.md §7]
